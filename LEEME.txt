TOYA Productos Naturales — Sitio web compilado, listo para publicar
==================================================================

¿Qué contiene este ZIP?

   - LEEME.txt   → este archivo
   - toya-web/   → el sitio web COMPLETO y COMPILADO (nueva versión)
                   Contiene index.html, imágenes, estilos y scripts.
                   No necesitas instalar ni programar nada.


TU SITIO YA ESTÁ EN LÍNEA:
   https://toyaproductos.netlify.app   (desplegado desde tu repo de GitHub)


CÓMO PUBLICAR ESTA NUEVA VERSIÓN (flujo GitHub, ~3 minutos):

   1. Descomprime este ZIP → obtienes la carpeta "toya-web"
   2. Entra a tu repo  https://github.com/NeoDirac/toya
   3. Botón "Add file" → "Upload files"
   4. Abre la carpeta "toya-web", selecciona TODO su contenido
      (Ctrl+A / Cmd+A — el contenido, no la carpeta) y arrástralo
      a la zona de carga de GitHub
   5. Mensaje del commit: por ejemplo "nueva version con fotos y logo"
   6. Botón "Commit changes"
   7. Netlify publica el cambio automáticamente en 1–2 minutos

   (Los archivos viejos que queden en el repo no molestan: los nuevos
   reemplazan a los que tienen el mismo nombre.)

   Si prefieres Git desde tu computadora: clona el repo, borra todo el
   contenido excepto la carpeta .git, copia el contenido de toya-web/,
   y haz commit + push.


ALTERNATIVA SIN GITHUB (publicar en otro sitio de Netlify):

   1. Entra a  https://app.netlify.com/drop  (cuenta gratis, puedes
      entrar con Google)
   2. Arrastra la carpeta "toya-web" COMPLETA a la zona de arrastre
   3. El sitio queda publicado en segundos con URL provisional
   4. Para elegir nombre: Site configuration → Change site name
